# QEC Decoding Exercises

Interactive, phone-friendly exercises on quantum error correction (QEC) decoding for the course *Fundamentals 3*.

**Open the exercises:** <https://juliusrye.github.io/fundamentals3/>

## Exercises

| Exercise | Link |
| --- | --- |
| Sending a bit over a noisy channel | <https://juliusrye.github.io/fundamentals3/noisy-bit/> |
| Repetition code syndrome | <https://juliusrye.github.io/fundamentals3/rep-syndrome/> |
| Surface code syndrome | <https://juliusrye.github.io/fundamentals3/surface-syndrome/> |

## Running locally

The site is plain HTML, CSS and JavaScript with no build step. Open `index.html` in a browser, or serve the folder:

```sh
python -m http.server
```

then go to <http://localhost:8000/>.
